DOM Manipulation

Learn how to manipulate the DOM with JavaScript

1. Selecting Elements

Use these methods to select DOM elements:

  • document.getElementById() - Select by ID
  • document.querySelector() - CSS selector
  • document.querySelectorAll() - Multiple elements

Try selecting me with JavaScript!

2. Modifying Content

Change element content with:

  • element.textContent - Plain text
  • element.innerHTML - HTML content

Original content

3. Event Listeners

Respond to user interactions:

  • element.addEventListener() - Add event handlers
  • click, mouseover, keydown - Common events

Hover or click me!

4. Creating/Removing Elements

Dynamically modify the DOM:

  • document.createElement() - Make new elements
  • element.appendChild() - Add to DOM
  • element.remove() - Remove elements

Existing element

5. Styling Elements

Change styles dynamically:

  • element.style.property - Inline styles
  • element.classList - Add/remove CSS classes
